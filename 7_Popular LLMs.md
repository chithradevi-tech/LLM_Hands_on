# Popular LLMs

## What are Popular LLMs?

**Large Language Models (LLMs)** are AI models trained on massive amounts of text to understand and generate human language.

Different organizations have developed different LLMs for tasks such as chatting, coding, reasoning, translation, and summarization.

---

## Popular LLMs

| LLM          | Organization | Architecture | Best For                        |
| ------------ | ------------ | ------------ | ------------------------------- |
| GPT-4        | OpenAI       | Decoder-Only | Chat, coding, reasoning         |
| Llama 3      | Meta         | Decoder-Only | Open-source AI applications     |
| Gemini       | Google       | Decoder-Only | Multimodal AI, reasoning        |
| Claude       | Anthropic    | Decoder-Only | Long-context reasoning, writing |
| Mistral      | Mistral AI   | Decoder-Only | Efficient open-weight models    |
| Mixtral 8x7B | Mistral AI   | MoE          | Efficient large-scale inference |
| DeepSeek-V3  | DeepSeek     | MoE          | Coding and reasoning            |
| Qwen         | Alibaba      | Decoder-Only | Multilingual and coding         |
| Falcon       | TII          | Decoder-Only | Research and open-weight AI     |
| Phi-3        | Microsoft    | Decoder-Only | Small, efficient LLMs           |

# Categories of LLMs

### 1. Closed-Source Models

* GPT-4
* Gemini
* Claude

Features:

* Commercial APIs
* Strong reasoning
* Regular updates

---

### 2. Open-Weight Models

* Llama 3
* Mistral
* Mixtral
* Qwen
* Falcon
* Phi-3

Features:

* Can often be downloaded and run locally (depending on the license and model size)
* Popular for research and custom fine-tuning

---

# Which Models Use MoE?

Examples:

* Mixtral 8x7B
* DeepSeek-V3

These activate only a subset of experts for each token.

---

# Which Models are Dense?

Examples:

* GPT-4 (exact internal architecture has not been publicly disclosed)
* Llama 3
* Gemini (exact internal architecture has not been fully disclosed)
* Claude (exact internal architecture has not been fully disclosed)

Most modern LLMs use a Decoder-Only Transformer architecture, while some models like Mixtral and DeepSeek-V3 use a Mixture of Experts (MoE) architecture for greater computational efficiency.**
